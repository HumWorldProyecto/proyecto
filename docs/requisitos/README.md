# Requisitos

HumWorld mantiene distintos niveles de definición y trazabilidad para evitar mezclar necesidades funcionales, especificaciones técnicas y decisiones arquitectónicas.

## Niveles de trazabilidad

- **Backlog:** los GitHub Issues HU-01 a HU-21 representan las historias funcionales del producto y están indexados en el [backlog de producto](../planificacion/backlog.md).
- **Especificación refinada:** [OpenSpec](../../openspec/) contiene proposal, spec, design y tasks para las capacidades que ya han pasado por refinamiento dirigido por especificaciones.
- **Arquitectura y decisiones:** [architecture.md](../architecture.md) establece el baseline y las restricciones; los [ADR](../adr/) registran decisiones relevantes.
- **Planificación:** [docs/planificacion](../planificacion/) organiza backlog, calendario, Sprint Goals y Definition of Done.

Esta carpeta actúa como índice de trazabilidad. No duplica manualmente las especificaciones detalladas de GitHub Issues u OpenSpec, porque mantener copias paralelas favorecería divergencias entre fuentes de verdad.
