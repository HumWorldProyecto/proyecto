# ADR

Esta carpeta contiene los registros de decisiones arquitectónicas tomadas durante el desarrollo de HumWorld.

## Convención

- Los archivos utilizan el formato `ADR-NNN-descripcion.md`.
- Cada número identifica una decisión y no se reutiliza.
- Cada ADR registra como mínimo su estado, contexto, decisión, alternativas consideradas y consecuencias.
- Una sustitución futura debe registrarse en un ADR posterior e indicar expresamente qué decisión reemplaza.

`ADR-001` ya fue asignado a «Integración mediante Pull Requests» en la historia del repositorio y no se reutiliza en este cambio.
