## Nota de trazabilidad

En P3 se identificaron requisitos técnicos junto al backlog. Tras P4 y P5, el equipo separó explícitamente:

- historias funcionales;
- trabajo técnico;
- requisitos no funcionales y transversales.

Las actividades técnicas apoyan la entrega de las historias, pero **no se contabilizan como nuevas historias de usuario**.
